Sobre o Sistema

O Sistema de Sala Inteligente foi desenvolvido para monitoramento ambiental em tempo real, integrando sensores IoT para garantir o conforto e segurança dos ocupantes.

Objetivo

Monitorar temperatura e presença para otimizar o uso da sala e garantir o conforto dos ocupantes.

Tecnologias

  • ESP32 com sensor DHT22 (temperatura)
  • Sensor PIR (presença)
  • Supabase (Auth + Database)
  • HTML5, CSS3, JavaScript
  • MQTT para comunicação
